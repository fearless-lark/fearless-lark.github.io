# RemiLink — Project Context

## How to Use This Documentation

`docs/strategy/` is the company's approved business strategy — the foundation for ALL work on this project.

- **Read strategy docs FIRST** before writing any website content, code, marketing copy, or making design decisions
- **Every decision must be grounded** in these docs — positioning, messaging, pricing, CTA wording, service descriptions, target audience
- **Do not contradict** the strategy. If your work conflicts with what's in the docs, the docs win unless you have an explicit approval
- **Suggesting changes is fine** — the docs evolve. But don't silently drift from them
- Files marked `Status: APPROVED` are current decisions. `Status: DRAFT` means the structure is set but details are still being filled in
- When in doubt, check `docs/strategy/gaps-and-open.md` for what's resolved vs. still open

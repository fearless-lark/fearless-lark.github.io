# Founder Inputs

This section is the tracked, current source of truth for founder-derived business inputs.

## Authority Rule

- Use this `founder-inputs/` section for current documentation decisions.
- Treat the raw files in `docs/notes/` and the local brandbook files as archival source material.
- If a raw note conflicts with a tracked page, update the tracked page deliberately instead of reinterpreting scattered notes ad hoc.
- Preserve uncertainty honestly. Do not upgrade a weak or speculative founder thought into a settled public claim.

## Status Legend

| Status | Meaning |
|---|---|
| `Confirmed` | Explicitly stated in the founder notes or written competitor note. |
| `Inferred` | Strongly supported by repeated signals across the notes, but still a synthesis rather than a direct quote. |
| `Exploratory` | An idea, workflow, tool, offer, or strategic direction the founder is considering but has not committed to. |
| `Open` | Missing, contradictory, unsupported, or still requiring a decision, proof, or source. |
